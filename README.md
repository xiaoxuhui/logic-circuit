# 逻辑工坊 · NAND LAB

左侧“我的世界模式”可将当前电路和自定义门内部转成内置红石风格方块，输入为拉杆，输出为红石灯。WASD 移动，空格上升，Shift 下降，点击画面后鼠标控制视角，Esc 释放鼠标；也可按住画面拖动视角。支持总览、回到入口、飞行速度和屏幕移动按钮。“重新转换”读取最新状态，“返回电路”回到原画布。按用户要求只提供结构与当前信号的观察，不导出游戏文件。

三维观察使用本地打包的 Three.js 0.160.1（MIT），许可及来源校验记录位于 `src/vendor/`；不需要在线加载引擎或游戏素材。

v0.3.1。离线数字电路沙盒：从与非门和延迟线开始，在无限画布组合电路，封装并编辑自定义逻辑门。

## 运行

无需安装运行依赖。执行 `node scripts/build.cjs`、`node scripts/serve.cjs`，打开 http://127.0.0.1:4196/ 。也可直接打开 `dist/index.html`。全部资源为本地相对路径。

## 操作

- 从左侧按住元件拖到画布；左键拖动主体移动，空白或端口左键拖动布线。空白右键拖动平移，滚轮缩放。左键拉线时同时按住右键可边平移边布线；松开右键继续拉线，松开左键完成连接。右键元件打开状态、替换及带宽面板，外部面板可删除；外部导线右键直接删除，内部导线右键保留。
- Shift＋左键拖动框选，拖动所选主体整组移动；Ctrl+A 全选，Delete/Backspace 删除，空格顺时针旋转。Ctrl+C 复制内部连线和元件，Ctrl+V 后整组跟随鼠标，左键放下、Esc 取消。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
- 输入/输出/延迟支持 1–256 位，集线器/分线器支持 2–256 位，位宽直接填写。每个二进制数字固定占一格，输入可逐位点击。输入输出下方显示对应数值，底部全局选择无符号十进制、有符号补码十进制或十六进制。
- 延迟线初始输出 0，下一步运行时同时采样所有延迟线，多级串联每步推进一级。支持自动运行、暂停、0.1–60 步/秒和重置。
- 左键选中导线后，可在属性应用临时数值，覆盖当前驱动且传播后级。切换输入不清除；下一步先采样再清除，临时值不进入持久存档。
- 用输入输出标记接口并封装，允许零输入/零输出。自定义门采用按需真值表，含延迟线时将当前寄存器作为额外输入，同时缓存下一状态；纯组合反馈保留原收敛规则与诊断，源电路始终保留。
- 右键“我的逻辑门”进入内部，编辑模式只显示直接子门，查看模式递归展开只读结构。更改写回同一定义，所有直接/间接引用同步更新；保存并返回原电路后可整体撤销。删除接口会移除其外部接线，撤销可恢复。
- 左键单击画布自定义门，按原始编辑布局查看该实例的当前状态，直接子门保持封装，保留当前输入、总线值及延迟状态；“退出”或 Esc 返回原电路和视角。这是状态查看，不进入定义编辑模式；拖动主体仍然移动。
- “全部展开”查看整个电路，可切换原输入后收回；门内查看模式保持只读。线路保持信号原色，自动布线绕开门体和其它线的重合段，交叉点不自动接通。拥挤端口使用分开的短引线，优先零重叠；无零重叠路径时按连续重叠次数、重叠长度、路径长度依次择优。门体仍必须避开，确实无安全路径时保留原电路并提示。加载或进入门编辑时修复可安全调整的旧重叠线，保留分支连接和原信号。
- 统计栏显示 NAND、延迟、集线器、分线器数量，按每个实际实例递归累加，不按类型去重。
- 自动保存到独有键 `logic-workshop-v1`；全部导出/文字导入保存画布与整个门库。全部删除并导出先备份再清空，可撤销。存储仅在当前浏览器/宿主内，迁移时使用存档。

## 验证与大厅

0.2.8 修复固定端口引线漏掉窄通道：优先寻找可用的零重叠路线，再使用最少重叠降级。较短出口仍保留门体安全间距。

`pnpm install --frozen-lockfile` 安装固定浏览器测试依赖；`pnpm test` 执行核心测试，`pnpm exec playwright install chromium` 后执行 `pnpm run test:browser` 运行完整与分功能浏览器回归。Windows 可设置 `PLAYWRIGHT_BROWSERS_PATH` 为现有 Chromium 缓存。

`game-hub.integration.json` 描述稳定 ID、六个离线运行文件和存储合同；大厅从固定 Git 提交消费 dist，动态资源安装无需更新 APK。发布状态见 doc/GitHub与大厅接入报告.md。源码按 MIT 许可提供。

每画布最多 500 个元件、1500 根导线，80 个自定义门，12 层嵌套；存档上限 2MB。

刷新、关闭及删除前后会自动备份完整电路；右上角“备份”可按时间恢复最近 10 份不同内容，恢复后可撤销。备份只保存在当前浏览器，也建议通过“全部导出”另存文件。读取失败时保留原存档，避免空白画布覆盖。

删除元件、导线或保存门时，立即备份删除前后两份状态；内部编辑的备份保存完整原电路。无递归自定义门最多支持32层嵌套。

0.3.0：含延迟线的自定义门使用按需状态真值表，输入与当前延迟值相同则直接复用输出和下一状态；首次遇到的组合才计算，内部结构仍可查看和编辑。刷新前同步备份；保存与备份都失败时，浏览器提示是否取消离开。主记录写入失败而备份成功，可在刷新后自动恢复。

本地补充：所有模式的导线均可设置临时输入。单比特左键直接切换0/1，多比特填写数值；下一步采样后清除，不写入封装或存档。本轮按用户要求提交推送，并发布到游戏大厅。

0.3.0：所有连线均按接收端位宽自动补零或截断高位，不同宽度驱动按最大来源位宽逐位或合并。位宽不同的有效端口连线在替换元件时保留。

0.3.1：替换元件保留输入输出连线；不存在的端口保留原位置线头，内部接口变化也不删除外部实例的线路。
