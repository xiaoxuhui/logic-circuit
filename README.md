# 逻辑工坊 · NAND LAB

v0.1.0。只有与非门的数字电路沙盒：在无限画布布线，把自己的电路封装为可重复使用的逻辑门。

## 开始

无需安装依赖，直接用浏览器打开 `dist/index.html` 或根目录 `index.html`。推荐通过本地服务使用，以获得稳定的浏览器自动保存：

```powershell
node scripts/build.cjs
node scripts/serve.cjs
```

访问 http://127.0.0.1:4196 。端口可用 `PORT` 环境变量覆盖。

## 操作

- 按住元件库里的元件拖到画布，松手放置；初始画布只有一个 NAND。基础门与自定义门操作相同，仅点击不会自动放置。
- 左键拖动门体移动；从空白或端口拖动布线，松开完成。
- 端点吸附到端口或导线时连接。线与线单纯交叉时不连接；输出支持多路扇出。
- 空白处按住右键拖动平移无限地图；兼容空格拖动/中键拖动，滚轮缩放。触屏使用“移动”和缩放按钮。
- 单比特输入点击开关切换信号；多位输入默认显示补足位数的二进制，如 0000，直接在门体或属性栏输入 0/1，按 Enter 或离开字段提交。选中元件可重命名或设置位宽。
- 集线器/分线器支持 2–8 位；拖入画布时填写线数 N，确认后才放置，单击已有元件可再次填写。集线器将 N 根单比特线合为总线，分线器将总线拆为 N 根；顶部 b0 为最低位。多位输出使用数字屏显示十进制值，例如输入 1010 时显示 10，单比特输出继续使用指示灯。
- 用输入和输出元件标明边界，点击“封装为逻辑门”，从左侧拖出再次放置。端口按边界元件由上到下、由左到右排序。可嵌套复用。
- 在“我的逻辑门”中点击每条旁的 ×（手机为“删除”），或右键该条目，可删除保存的门。画布上已放置的门和其他门内部使用的电路继续运行；Ctrl+Z 可撤销这次删除。
- Ctrl+A 全选画布元件，Backspace / Delete 或删除工具一次删除所选元件及关联连线，Ctrl+Z 一次恢复。单独绘制的自由导线和元件库保留；输入框中的快捷键继续编辑文字。
- 点击画布右上角“全部展开”递归查看所有自定义实例的原始门、接口与实际信号；此时为只读查看，可平移缩放。按钮变成“全部收回”，点击后一次恢复全部门及原视角。展开不修改电路或撤销记录，保存/导出仍保留原电路。
- 右键单击元件或导线直接删除，无需先选中；删除门时同时移除它连接的导线。也可用 Delete 删除选中对象。右键从对象上拖动不会误删。Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；Esc 取消绘制或选择。
- 自动保存在当前浏览器；顶部“全部导出”用一个 JSON 文件保存全部电路、导线、自定义门（含嵌套依赖）与视角，“全部导入”选择这个文件即可整体恢复，替换当前画布和门库。兼容原有存档，导入和新建均可撤销。
- 左侧元件库底部的“全部删除并导出”先提示操作范围，确认后下载完整存档，再清空所有元件、导线和“我的逻辑门”。请保存好下载文件；若取消下载或想恢复，可按 Ctrl+Z 或点击撤销按钮，一次恢复全部内容。全部展开期间不可清空。

薄荷绿为高电平 1，蓝灰为低电平 0。未接线或没有有效驱动的输入默认为低电平，不再使用未知信号。多个输出接在一起、位宽不一致仍会提示连接错误。本版本用于组合逻辑；不提供时钟与触发器，反馈回路未收敛时提示错误，并将计算元件输出设为低电平。

## 验证

```powershell
node --test tests/core.test.cjs tests/expanded.test.cjs
node scripts/build.cjs
node tests/browser.cjs
```

核心测试无外部依赖。浏览器测试需要 Playwright 和对应的 Chromium；会自动使用 Codex bundled runtime 中的 Playwright。Windows 若缓存路径在用户目录，可设置：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH="$env:LOCALAPPDATA\ms-playwright"
node tests/browser.cjs
```

支持 npm 的环境也可使用 `npm test`、`npm run build`、`npm run test:browser`、`npm start`。

源代码：`src/core.js` 为纯电路模型，`src/expanded.js` 为展开布局与信号视图，`src/app.js` 为画布与交互。最新测试证据见 `doc/全部存档测试报告.md`。

当前单画布最多 500 个元件、1500 根导线，支持 80 个自定义门、12 层嵌套；导入限制 2MB，以控制浏览器资源使用。画布可自由向任意方向平移。
