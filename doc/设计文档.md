# 设计文档

版本：0.1.0；状态：实施中。实现策略：零运行时依赖，HTML/CSS/SVG 与原生 JavaScript，支持直接打开与静态托管。

## 设计目标

1. 主区域留给画布；深色网格、薄荷绿高电平、灰蓝低电平、琥珀未知，端口和位宽明确。
2. 操作与用户描述一致：从库拖出放置元件，放下后门体拖动移动，空白左键拖动布线，右键拖动平移。工具栏提供移动模式用于触摸，保留空格/中键拖动作为兼容操作。
3. 模型与交互分离；用 Node 内置测试运行器穷举真值组合和总线。

## 分层

- src/core.js：节点/端口、几何吸附、网络分组、三值信号传播、总线、嵌套自定义门、存档校验。
- src/app.js：SVG 渲染、指针手势、相机、工具栏、检查器、历史记录、存储与对话框。
- styles.css / index.html：响应式中文界面、键盘焦点、帮助与封装表单。
- scripts：静态构建与本地服务。
- tests：核心行为和真实 Chromium 浏览器操作。

## 数据与规则

存档版本 1：nodes、wires、definitions；相机与元件值一同保存。节点使用稳定 id；端口锚点使用 node、dir、port，空白锚点使用世界坐标。折线端点接触导线构成连接，纯交叉不连接。单端口可扇出；不同输出冲突为未知并报告。未连端口为未知；NAND 任一输入为 0 时输出 1，两输入为 1 时输出 0，否则未知。

集线器 b0 在顶部，每输入单比特；总线按 [b0,b1,…] 表示。封装电路按输入/输出节点 y、x 排序，复制电路快照引用既有定义，不允许递归引用。自定义门的输入输出位宽继承边界元件位宽。迭代至稳定或有界停止，未知反馈显示为未知。

存档严格校验类型、数量、引用、数值与自定义依赖；先完整校验再替换画布。文件大小限制 2MB。撤销/重做只记录内容变更，相机移动不占历史。

## 直接拖出放置（用户补充，2026-10-17）

元件库不使用浏览器原生 HTML drag-and-drop。统一 Pointer Events 同时支持鼠标与触摸，按下后显示独立浮动 SVG 预览，捕获指针，拖动时只更新预览；在画布内释放才向电路提交一个新节点。中心跟随释放点，坐标经相机反变换后按 12 世界单位吸附；不自动寻找空位，也不自动适配视图。画布外松手、Esc、pointercancel 和失焦全部取消。点击保持无操作。右键始终优先启动平移，即使起点在门体、开关或端口上，也不改变电路。

## 二进制输入与数字输出（用户更正，2026-10-17）

存档 value 保持数值格式兼容。多位输入的画布使用 SVG foreignObject 中的文本输入框，属性栏也使用二进制文本。仅在 Enter/change 提交，验证长度及字符后以 radix 2 解析并记录一次历史；无效输入恢复原值。渲染时按位宽补足前导 0。鼠标在字段中可选择编辑，右键仍可平移。多位输出以矩形数码屏显示十进制结果，未知显示 ?，单比特输出继续画灯。
