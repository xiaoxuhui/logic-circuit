# 设计文档

## 保持 IO 分组与实时门调试

输入集合和输出集合各作为一个布局块，成员使用原节点坐标减去本组最小坐标，只平移整块；内部逻辑门继续分列排布。IO 保留原包围盒和旋转方向，图中坐标差与源电路一致，接口映射仍按定义端口 ID/索引而非显示位置。布局块之间留出独立走线通道。

复用展开视图作为实时调试器。右键 NAND/自定义门进入并标记目标；可切换的是原电路源输入，所有派生接口只读。输入专用事务只更新 value、重建展开信号图，保留当前调试视角并正常记录历史与存储。返回只恢复原来的画布视角及模式，不回滚用户确认要保留的输入变化。侧栏也提供源输入位按钮，便于目标门很远时操作。返回按钮与 Esc 统一退出；导出、自动保存仍为源电路。

## 展开布局与旋转

采用直接的布局修复：保留原列与封装接口顺序，加大元件间距；每个网络分配独立干道和端口引出通道，从元件外侧走线，点击可高亮查看端点；显示布局不参加信号求值。旋转为节点可选 rotation 字段（0/90/180/270），保留版本 1 存档；基础尺寸与旋转后包围盒分离，端口按同一变换计算，绕中心旋转，结构历史复用现有事务。

## 点击二进制位与存档文字

多位输入使用 SVG 位按钮与属性面板 HTML 按钮，共用 toggleBit(id, bit)，通过 XOR 切换指定位，原 value 数字与位宽不变。从高位到低位排列，明确 b 位序和 aria-pressed。位按钮的指针不启动节点拖拽；触屏使用现有释放即激活机制，同时抑制兼容 click 重复调用。键盘空格由位按钮消费，避免启动平移。重绘后恢复同一按钮焦点。

兼容 click 的抑制按逻辑门 ID 和位索引匹配，避免重绘换了 DOM 节点后，同一次触摸又被当成第二次点击。

展开默认缩放至少 80%，从左侧输入开始查看，适配按钮仍可显示全图；每层独立网络横向干道位于元件上方，端口垂直引线位于列间空隙，输入/输出编号按已保存的接口数组排列。不同网络不共享同轴线段，真实信号继续取原坐标电路的模拟结果。

旋转后的端口自动走线可能视觉交叠。已明确引用端口的连接按 node/dir/port 身份归组，只有自由端点才用几何位置形成支路，避免旋转导致两路输入短接。保留自由线 T 接及端点接到端口的规则。

导入对话框添加 textarea，复用统一 importAllText 校验与替换。手动复制使用 clipboard.writeText，失败时仅选中已生成文本供 Ctrl+C；不读取剪贴板。旧文件入口移到对话框内，文件内容进入同一校验通路。文字与文件都限制 2MiB，错误只显示消息，不提前清空。复制源仍包含隐藏嵌套依赖和原始视角。

## 2026-10-18 全部存档操作

复用版本 1 存档与导入校验；抽取统一 exportAll 下载函数，导出 snapshot 和原始视角，不改变信号模型。“全部导出”调用同一函数；新增元件库底部的“全部删除并导出”入口，确认对话框展示范围与数量，成功发起下载后才用一个 change 事务置空 nodes、wires、definitions。导出抛错则保留源数据。浏览器下载是否最终保存无法检测，界面明确可 Ctrl+Z 恢复。全部导入直接复用现有文件选择与整体替换，不做部分合并。展开状态禁止清空，触屏使用已有按钮机制；底部入口窄屏可换行，顶部仅修改两处按钮文案。

版本：0.1.0；状态：实施中。实现策略：零运行时依赖，HTML/CSS/SVG 与原生 JavaScript，支持直接打开与静态托管。

## 设计目标

1. 主区域留给画布；深色网格、薄荷绿高电平、灰蓝低电平、琥珀未知，端口和位宽明确。
2. 操作与用户描述一致：从库拖出放置元件，放下后门体拖动移动，空白左键拖动布线，右键拖动平移。工具栏提供移动模式用于触摸，保留空格/中键拖动作为兼容操作。
3. 模型与交互分离；用 Node 内置测试运行器穷举真值组合和总线。

## 分层

- src/core.js：节点/端口、几何吸附、网络分组、三值信号传播、总线、嵌套自定义门、存档校验。
- src/app.js：SVG 渲染、指针手势、相机、工具栏、检查器、历史记录、存储与对话框。
- styles.css / index.html：响应式中文界面、键盘焦点、帮助与封装表单。
- scripts：静态构建与本地服务。
- tests：核心行为和真实 Chromium 浏览器操作。

## 数据与规则

存档版本 1：nodes、wires、definitions；相机与元件值一同保存。节点使用稳定 id；端口锚点使用 node、dir、port，空白锚点使用世界坐标。折线端点接触导线构成连接，纯交叉不连接。单端口可扇出；不同输出冲突为未知并报告。未连端口为未知；NAND 任一输入为 0 时输出 1，两输入为 1 时输出 0，否则未知。

集线器 b0 在顶部，每输入单比特；总线按 [b0,b1,…] 表示。封装电路按输入/输出节点 y、x 排序，复制电路快照引用既有定义，不允许递归引用。自定义门的输入输出位宽继承边界元件位宽。迭代至稳定或有界停止，未知反馈显示为未知。

存档严格校验类型、数量、引用、数值与自定义依赖；先完整校验再替换画布。文件大小限制 2MB。撤销/重做只记录内容变更，相机移动不占历史。

## 直接拖出放置（用户补充，2026-10-17）

元件库不使用浏览器原生 HTML drag-and-drop。统一 Pointer Events 同时支持鼠标与触摸，按下后显示独立浮动 SVG 预览，捕获指针，拖动时只更新预览；在画布内释放才向电路提交一个新节点。中心跟随释放点，坐标经相机反变换后按 12 世界单位吸附；不自动寻找空位，也不自动适配视图。画布外松手、Esc、pointercancel 和失焦全部取消。点击保持无操作。右键始终优先启动平移，即使起点在门体、开关或端口上，也不改变电路。

## 二进制输入与数字输出（用户更正，2026-10-17）

存档 value 保持数值格式兼容。多位输入的画布使用 SVG foreignObject 中的文本输入框，属性栏也使用二进制文本。仅在 Enter/change 提交，验证长度及字符后以 radix 2 解析并记录一次历史；无效输入恢复原值。渲染时按位宽补足前导 0。鼠标在字段中可选择编辑，右键仍可平移。多位输出以矩形数码屏显示十进制结果，未知显示 ?，单比特输出继续画灯。

## 右键快捷删除（最新规则）

覆盖上述右键从任意位置平移的行为。右键按下时根据命中对象选择手势：空白是 pan，元件（含端口、开关、二进制字段）或导线是 right-delete。后者记录目标 id、初始屏幕点与移动阈值；只在同一目标上释放、累计未超过 6 像素且未取消时，复用统一删除事务。拖动过程中超过阈值后即使移回也不删。删除保存一条历史并立即重算信号；禁止在 contextmenu 中重复删除。保留空格/中键与移动工具作为其他平移方式。

## 删除已保存的逻辑门

语义限定为从“我的逻辑门”元件库移除，不拆除既有电路。被删除但仍在画布或其他门内部使用的定义标记 hidden: true，保留实现以维持信号、端口和存档兼容。未使用的定义真正移除。每次内容事务后，以可见定义和画布上的自定义实例为根，遍历嵌套引用并清理不可达的隐藏定义。版本号仍为 1，hidden 为可选布尔值，旧存档默认可见。

每一行使用两个并列按钮，拖出按钮与删除按钮分离，避免嵌套 button 或误开始拖放。右键条目复用删除事务；拖放过程中不触发库删除。删除/撤销/重做使用已有历史和自动保存。

## 全选与总线线数

选择状态增加 nodes 类型，保存多个节点 id。Ctrl+A 仅作用于画布元件；删除统一将 id 集合用于节点和关联边的过滤，一次提交历史。编辑字段、模态对话框及正在进行的手势不接管全选。选中多个元件时检查器显示数量与删除提示。

总线工具使用专用线数表单。拖放后保留候选节点及世界坐标，打开空白数量字段；通过验证才创建节点。对已有集线器/分线器的门体单击打开同一表单，填入原数量；移动超过点击阈值则只移动，不打开表单。输入数量范围继续为 2–8，与当前信号和存档兼容。工具栏属性和表单复用同一位宽变更函数。

## 二值信号（覆盖三值规则）

信号只保留 0/1，未连接、悬空线或错误驱动使用全零向量。初始求值输出从低电平开始，NAND 按二值规则求值。位宽不符、多输出驱动仍报告连接错误；迭代未收敛时报告反馈错误，并把非输入元件输出清为 0，避免把任意最后一次迭代结果显示成稳定逻辑。界面移除未知图例和 ?，未接线输出显示 0。

## 全部展开/收回

展开以只读视图实现，源模型始终保留，避免引入收回后保存内部修改的新规则。src/expanded.js 递归生成布局与 SVG：自定义门变为带名称的框，所有内部自定义门继续展开，输入输出标记显示为边界接口，最终叶节点为 NAND/总线工具及最外层输入输出。信号取自源模型每层模拟，外部输入通过边界传入，避免为显示重排造成网络误连接。布局按源坐标的列与行排序，自动让开展开后的框。UI 保存原视角和工具，展开中允许平移缩放；保存/导出仍是源模型。收回恢复原视角和编辑状态。

2026-10-18 用户纠正：调试入口为左侧“我的逻辑门”条目的右键，进入该保存门的内部电路，返回恢复原画布；保留调试时修改的门内输入默认值。画布门右键继续删除。允许无输入、无输出或两者皆无的门封装保存。

2026-10-18：新画导线和拖动预览默认绕开元件，按旋转后的包围盒留空隙；新导线移动/旋转元件后自动重新避让。旧导线和既有连接端口保留。

2026-10-18：自动布线允许单点交叉，避开不同导线共用同一段；同一端口分支采用不同引出方向，移动重算时忽略导线自身。


### 延迟线运行
`delay` 为等位宽输入/输出组件。运行时状态保存在根存档 delayState，以 root/实例/内部节点路径隔离自定义门实例。step 依据同一份旧状态递归采样，最后原子更新；组合仿真只读取状态。展开视图使用相同路径，封装定义不包含运行时状态。自动运行按用户速度推进，“延迟线清零”清空整棵实例树的运行时状态；清零与返回原电路会暂停运行。


### 真值表编译
按实际电气网络构建依赖图并拓扑排序，递归检查嵌套门；延迟、环路、非法网络均回退电路模拟。安全门按输入位序查表，小表预生成、大表按需缓存；缓存按完整定义内容失效，不信任导入的缓存数据。源电路始终保留，展开仍使用原节点及连线。


### 宽位宽存储与布局
安全整数保持旧存档数值格式，超过安全整数的值使用二进制字符串；计算位数组及十进制显示使用 BigInt 转换以避免 32 位位运算和浮点精度丢失。数字格宽度固定 24，输入宽度随位数增长，输出宽度按最大十进制位数预留。位宽调整后更新端口和自动布线。


### 数值对照显示
输入输出共用精确十进制换算，在数字格下方显示 decimal-summary；输出格逐位显示完整二进制，宽度与输入按位数预留，元件副标题下移避免重叠。


### 框选与应用内剪贴板
marquee 手势优先于布线和平移，使用世界坐标与旋转后包围盒计算命中。应用内剪贴板保存元件、闭合所选网络中的线路及递归依赖定义；粘贴重新映射节点/线路/定义标识并平移自由端点和路径，使用 change 原子提交。


### 粘贴预览
剪贴板生成独立 ID 的待放置片段，复用元件/导线渲染到独立预览层；只用世界坐标平移跟随鼠标。确认时一次提交片段及依赖定义，取消不改变状态、历史或存档。


### 格式切换
每个 IO 节点保存 displayFormat（unsigned/signed/hex），缺省 unsigned。公共 formatValue 使用 BigInt，signed 在最高位为 1 时减去 2^位宽，hex 带 0x 前缀并按位宽补足十六进制位。展开根节点可切换格式，库调试将格式写回原定义。


### 全局数值模式
根存档 displayFormat 为统一显示偏好，旧节点字段兼容读取但不作为当前显示依据。工具栏常显选中的模式；展开递归共享源电路的全局格式，调试子电路继承且同步回原电路。


### 整组拖动
nodes 手势记录初始快照、各节点位置以及仅包含所选端口的完整网络；拖动使用同一网格对齐增量平移节点及内部路径/自由端点，外部端点保持并重新自动布线。拖动完成原子提交，取消恢复快照。


### 门编辑会话
独立 gateEditor 保存主画布、相机和历史。普通画布作为定义编辑区，每次提交通过 updateDefinition 写回共享定义并修复根及其它定义内的实例端口索引。快照含编辑会话根电路以保证撤销恢复接口连接。保存导出使用根电路，编辑时的库禁用自身及依赖自身的条目防止递归。真值表内容签名自动失效。


### 双模式视图
编辑继续使用普通画布；查看复用 expanded 并标记 libraryView，构建时 readOnly 移除输入交互属性，沿用展开态结构编辑保护，另禁用模拟步进和重置。两种视图各自保留相机，切换不重写定义。


### 元件统计
countComponents 遍历当前画布节点，递归计算自定义门的底层 NAND 与 delay 数量，对同一定义的子计数记忆化，每个实例分别累加。统计与真值表计算方式及展开可见性无关。


### 重复实例统计规则
定义缓存仅缓存单个实例的内部组成，不标记实例已统计；遍历每个 custom 节点时都累加四类子计数。移动端统计栏换行显示，避免四项溢出。


### 强制网络信号
运行时 wireOverrides 以导线 ID 保存位数组；simulate 构建对应网络覆盖，read 优先返回强制值，包括有驱动冲突的网络。设置时移除同网络旧覆盖。根作用域隔离嵌套模板的同名导线；下一步先 sample 再清空，历史快照保留而存档去除运行时覆盖。


### 大厅接入
保持稳定游戏 ID logic-circuit、存储键 logic-workshop-v1，版本 0.2.0/contentCode1。大厅锁定源仓 dist 的六个静态文件，资源合同 logic-circuit-dynamic-v1，不变更原 APK。浏览器下载由大厅既有 blob 导出桥承接，存档文字导入可作降级。

### 实例内部查看
LogicExpanded.focus 从主电路模拟结果取得指定 custom 实例端口值，复制定义的内部节点并写入对应输入，按 root/实例 前缀映射延迟状态到局部 root。direct/preserveLayout 选项保留原始节点位置、旋转和导线路径，仅渲染直接层级，自定义子门仍作为封装块；显示当前状态但不进入定义编辑。主 state 始终保留原电路；expanded.instanceView 区分单实例查看，停用时序控制与可切换输入，独立“退出”按钮恢复相机。单击入口在 node 手势释放且未移动时触发，不影响移动、端口布线、库编辑与全部展开。

## 逐层状态查看
focus 返回捕获信号后的局部电路，下一层以该局部电路为源。界面维护查看帧栈，各帧保存视图、目标和相机；根电路保持独立，返回逐层恢复相机。数字格式更新所有查看帧，避免深层误取根节点。

## 仿真与选择分离
选择仅更新高亮、属性和工具状态。仿真会话缓存连接拓扑、计算顺序和逐实例结果，以精确结构/输入/本实例延迟状态识别失效；定义改变清空会话缓存。无环拓扑单次计算，组合反馈保留原有有界迭代。缓存不写入存档。

## 刷新备份
使用独立 logic-workshop-refresh-backups-v1 存储键，条目含时间、原因及完整存档文字；重复内容不增加条目，最多 10 份，写满时逐步丢弃最旧备份，绝不清空主存档。beforeunload/pagehide 同步执行，退出事件不弹确认。保存的是原电路与编辑后的定义，查看帧不进入存档。页面入口提供带时间和元件/门数量的恢复列表；恢复前备份当前内容，恢复可撤销。

## 删除备份与统一嵌套限制
提交时比较删除前后元件/导线标识及门删除标记，删除前保存before快照；编辑内部时取before.editorRoot作为完整原电路。成功后保存完整root，失败回退不写删除后。MAX_DEPTH统一为32，保留循环与总成本检查。

## 双键布线平移

方块批次改为直接写入可增长Float32Array，避免先积累普通数值数组再整体转换，返回时裁剪成紧凑可转移缓冲。边界直接按x/y/z更新，避免每个部件构造临时坐标对象。生成数据仍按原顺序逐值比较。


在既有简单直接路线失败后尝试端口朝向约束的分层通道：输入/输出沿合法方向逐格爬升，连接高层通道再逐格下降；逐点使用既有pathOK验证占用、支撑、头顶净空与网络隔离。仍保留A*兜底与最终连通性校验，不能靠穿透或跳过失败线路掩盖问题。


直接运行在现有物理模拟器上批量兑现所有待处理事件，不等待事件时间；每轮重算真实粉线强度。Worker以小批次与时间预算推进，稳定时发送结果；连续模式仅输入变化时重算。跟踪前64轮设备状态检测重复，最多4096轮，振荡时停止并提示。取消、切换、重建时丢弃直接计算任务。


通过下拉框的selected设置三维初始基础模式；空模型状态读取对应选择值。算法接口保持兼容，测试明确选择原NAND场景并单独检查用户默认入口。


持续模式跳过稳定值循环检测和总轮数上限，按12ms/31轮小批次持续兑现事件；每批更新显示，用0ms计时任务继续下一批，让出消息队列以响应停止。单次模式保留重复状态及4096轮限制。反馈运行必须在无输入操作下跨多个批次变化。


透明中继器由粉线/实体方块供电依赖驱动的队列一次闭包计算，移出定时事件列表，前台世界与网格保持。火把保留为唯一帧延迟，每30ms兑现上一帧火把事件，再重算零延迟中继器/灯；所有火把同步采样。持续调度与原生50ms时钟分开，模式切换重新排定事件，稳定时仍保持持续模式。


持续模式缓存静态粉线到有效受电方块的邻接关系，只计算火把附着块、中继器后端实体与灯附近的弱充能；从实际电源落点初始化粉线队列，避免每帧扫描每根粉线的六个邻格和重复计算弱充能。


在最终世界渲染遍历中顺便累加materialCounts，Worker随模型一次发送；显示六种材料，半砖如存在单列。运行帧只更新颜色，数量直接复用，避免每帧重数。手机统计自动换行，避免遮挡右侧模块列表。

保留原低层优先路径；失败后对所有电路尝试高层走廊和8/16/32/48层有界搜索。端口保护只保留实际电气安全高度，避免无限高的虚拟障碍封死上空。
# B103 自动汇流端口
生成汇流器时设置各分支入口方向和汇流输出方向，使既有端口预约与上层布线可以识别；保持多驱动逐位OR语义及物理隔离。
# B104 流向标记
优先采用路由已有的源到目标路径；门内部粉线按拉杆、火把及中继器输出端向外遍历补齐方向。箭头独立作为实例绘制，直线稀疏采样，转弯、端点、分叉保留；不写入物理世界或存档。
# B105 连续导向线
保留所有有向物理边，采样仅控制方向尖；平面边绘制整格线，坡道绘制下平台、竖段、上平台，构成连续阶梯。全部合入原实例批次，不影响世界状态。
# B106 屏幕尺寸方向标记
箭头尖改用GPU点精灵，按实际路径方向投影，固定22 CSS像素；连续线使用GPU投影计算最小像素宽度。视角变化只更新相机/视口uniform，不逐个修改实例。
# B107 稀疏标记
转弯不再绕过密度控制；分叉及边界标记具有单独优先级。GPU采样至少每4个候选显示一次，并按96像素目标间距进一步稀疏。
# B108 导向层可见性
独立可见性变量控制flowGuide实例批次与flow-heads点精灵。重新生成后重新应用；不删除物理格、不触发电路修改，不与整体隐藏界面状态耦合。
# B109 定义名称编辑
内部模式条提供静态名称输入框，复用现有change/commit历史与持久化流程；只修改当前定义name，保留ID与依赖引用。查看模式禁用改名；聚焦输入时避免重绘覆盖未提交文字。
# B110 入口装箱保护出口
输入装箱重叠检查将前方预留区从一格延伸至两格，使下一段线可离开拉杆避让区。失败不能仅增加搜索高度，因为拉杆避让列会阻断所有高度；先保证实际出口通道，再使用既有分层搜索。

B111测试设计：以同网粉线连通分量满足边数=顶点数−1作为无环判据；用明确世界坐标检验旧多余输出已消除。渲染实例数量只用于校验浏览器加载一致性，不再作为拓扑正确性的替代指标。

# B112 骨牌事件模型
新增独立domino-model与domino-view。编译只复用端口/网表定义，不调用原电路simulate计算输出；将NAND转换成两条时钟非门及汇流。输入倒牌先移除桥牌，后到的时钟在缺口停止；未移除则时钟传到输出。输出读末牌是否倒下，延迟跨轮统一采样。几何与时间网络共享同一连接表，工作线程运行事件，Canvas按视口绘制骨牌。参考实际骨牌计算机设计 https://www.andrewt.net/maths/domputer/ 。

B112用户补充：去掉公式提示；参考真实骨牌交互，不能让不相关线路交叉，也不能用抽象连边跨过碰不到的距离。采用无交叉的表达式树摆放（同名输入在多个位置同步设定），使用有方向的倒牌矩形与站立牌矩形碰撞传播；非门桥牌允许被输入先反向推倒，触发链后来无法越过。连接必须逐牌可接触，保留平滑弯道。

B112实现补充：按用户要求移除公式提示。真实几何接触驱动倒牌，弯道等距采样，桥牌缺口不能被跳过。同表达式在可安全走线且实际减少骨牌时共享，通过一张骨牌触发两个分支；重新计算所有触发等待时间，不牺牲连通性或允许直接交叉。全加器摆放从6708张减少到6274张，保留无交叉布置。

B112默认基础门补充：骨牌模式直接选择默认或门、默认异或门。同步触发的异或采用A/B从相反方向推动斜置交会牌，单路通过后两侧输出汇合；同刻相反推力合并处理，避免事件队列先后顺序决定结果。该示例依赖对称摆放、同时到达，属于离散接触模型；不把它当作能保留两个独立信号的普通跨线结构，也未据此替换任意异步电路内部的XOR。

B113三输入接线：明确进位为C_in。单源交叉器由3个原生同步异或门组成，2路直接分岔与中间信号分岔独立；下方门镜像以避免输出被输入线路围住。通过实际meander长度对齐到达时间，全部4行验证后才供观察。A/B/C_in示例使用3个独立单起点，进位绕外侧安全空白通道后分成2个预接端口，并逐项保留标签。任意主电路自动布线尚未替换为该例。

B114方案调整：任意网表平面布线无法仅靠避障保证完成。全加器改由两个共享的物理半加器、三异或跨线及最后的或门构成。A/B在第一半加器各一个起点；和信号进入第二半加器，进位源仅一个，使用真实延长链对齐和信号到达时间。进位各分支按实际骨牌接触传播。半加器的AND部分保留受触发链控制的非门结构，输出仅由骨牌状态读出。

全加器识别同时支持已有封装门和多位输入/输出边界。标准示例按结构识别；其他候选仅用原电路8行验证功能分类，后续运行完全使用骨牌碰撞，不用原电路计算输出。原网表、名称和值不修改。新增统计缓存，8行物理运行得到最大/最小步数；按钮仅切换当前骨牌副本。

## 自制门通用单源分岔
对存在重复叶输入的电路，将输入与延迟状态各保留一个物理起点。接收端按纵坐标排序，信号总线通过相邻三异或交叉器换位后向接收端分岔。各直通轨道与交叉轨道以实际骨牌接触校准同等传播步数，避免异或的异步误输出；最后测量所有叶输入到达时间，重新安排门的触发骨牌。每轮仍由几何接触驱动。原始电路只读，百万张牌上限保留。此修改解决输入信号分配，未声称已经消除所有重复中间门表达式。

## 电线世界
四态Moore邻域：空白固定，头转尾，尾转线，线周围恰有1或2个头时转头。内核只扫描活动电子前沿邻居与尾部，非空格用稀疏Map存储，颜色遵从用户指定。独立worker计算；无法创建worker时相同内核在主线程分片运行，仍按逐代规则。

转换器复用现有网表展开函数，仅用于连接关系。NAND展开为OR(NOT(A),NOT(B))，相同输入只生成NOT。NOT是受控制脉冲抑制的16代时钟结构，OR以三格前沿阻止反向串扰；输入是周期脉冲或无脉冲。直角线转角切斜，路径按实际格数对齐模16相位，输出在传播稳定后对应相位采样。快速运行仍逐代演化，分片只合并显示更新，不用电子计算器替换CA输出。延迟作为本轮输入，下一轮同时取CA采样结果。

独立键logic-workshop-wireworld-v1及logic-workshop-wireworld-backup-v1，保存CA当前状态、相机、转换源副本与输入值；恢复时重建布局并恢复场，原电路存档不变。清空/替换前备份；导入先验证。初版使用树形无跨线摆放，源可复制；非空格20万上限，无延迟的逻辑反馈不支持自动转换，自由绘制闭环不受此逻辑约束。
