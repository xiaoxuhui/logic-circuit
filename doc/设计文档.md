# 设计文档

## 展开布局与旋转

采用直接的布局修复：保留原列与封装接口顺序，加大元件间距；每个网络分配独立干道和端口引出通道，从元件外侧走线，点击可高亮查看端点；显示布局不参加信号求值。旋转为节点可选 rotation 字段（0/90/180/270），保留版本 1 存档；基础尺寸与旋转后包围盒分离，端口按同一变换计算，绕中心旋转，结构历史复用现有事务。

## 点击二进制位与存档文字

多位输入使用 SVG 位按钮与属性面板 HTML 按钮，共用 toggleBit(id, bit)，通过 XOR 切换指定位，原 value 数字与位宽不变。从高位到低位排列，明确 b 位序和 aria-pressed。位按钮的指针不启动节点拖拽；触屏使用现有释放即激活机制，同时抑制兼容 click 重复调用。键盘空格由位按钮消费，避免启动平移。重绘后恢复同一按钮焦点。

导入对话框添加 textarea，复用统一 importAllText 校验与替换。手动复制使用 clipboard.writeText，失败时仅选中已生成文本供 Ctrl+C；不读取剪贴板。旧文件入口移到对话框内，文件内容进入同一校验通路。文字与文件都限制 2MiB，错误只显示消息，不提前清空。复制源仍包含隐藏嵌套依赖和原始视角。

## 2026-10-18 全部存档操作

复用版本 1 存档与导入校验；抽取统一 exportAll 下载函数，导出 snapshot 和原始视角，不改变信号模型。“全部导出”调用同一函数；新增元件库底部的“全部删除并导出”入口，确认对话框展示范围与数量，成功发起下载后才用一个 change 事务置空 nodes、wires、definitions。导出抛错则保留源数据。浏览器下载是否最终保存无法检测，界面明确可 Ctrl+Z 恢复。全部导入直接复用现有文件选择与整体替换，不做部分合并。展开状态禁止清空，触屏使用已有按钮机制；底部入口窄屏可换行，顶部仅修改两处按钮文案。

版本：0.1.0；状态：实施中。实现策略：零运行时依赖，HTML/CSS/SVG 与原生 JavaScript，支持直接打开与静态托管。

## 设计目标

1. 主区域留给画布；深色网格、薄荷绿高电平、灰蓝低电平、琥珀未知，端口和位宽明确。
2. 操作与用户描述一致：从库拖出放置元件，放下后门体拖动移动，空白左键拖动布线，右键拖动平移。工具栏提供移动模式用于触摸，保留空格/中键拖动作为兼容操作。
3. 模型与交互分离；用 Node 内置测试运行器穷举真值组合和总线。

## 分层

- src/core.js：节点/端口、几何吸附、网络分组、三值信号传播、总线、嵌套自定义门、存档校验。
- src/app.js：SVG 渲染、指针手势、相机、工具栏、检查器、历史记录、存储与对话框。
- styles.css / index.html：响应式中文界面、键盘焦点、帮助与封装表单。
- scripts：静态构建与本地服务。
- tests：核心行为和真实 Chromium 浏览器操作。

## 数据与规则

存档版本 1：nodes、wires、definitions；相机与元件值一同保存。节点使用稳定 id；端口锚点使用 node、dir、port，空白锚点使用世界坐标。折线端点接触导线构成连接，纯交叉不连接。单端口可扇出；不同输出冲突为未知并报告。未连端口为未知；NAND 任一输入为 0 时输出 1，两输入为 1 时输出 0，否则未知。

集线器 b0 在顶部，每输入单比特；总线按 [b0,b1,…] 表示。封装电路按输入/输出节点 y、x 排序，复制电路快照引用既有定义，不允许递归引用。自定义门的输入输出位宽继承边界元件位宽。迭代至稳定或有界停止，未知反馈显示为未知。

存档严格校验类型、数量、引用、数值与自定义依赖；先完整校验再替换画布。文件大小限制 2MB。撤销/重做只记录内容变更，相机移动不占历史。

## 直接拖出放置（用户补充，2026-10-17）

元件库不使用浏览器原生 HTML drag-and-drop。统一 Pointer Events 同时支持鼠标与触摸，按下后显示独立浮动 SVG 预览，捕获指针，拖动时只更新预览；在画布内释放才向电路提交一个新节点。中心跟随释放点，坐标经相机反变换后按 12 世界单位吸附；不自动寻找空位，也不自动适配视图。画布外松手、Esc、pointercancel 和失焦全部取消。点击保持无操作。右键始终优先启动平移，即使起点在门体、开关或端口上，也不改变电路。

## 二进制输入与数字输出（用户更正，2026-10-17）

存档 value 保持数值格式兼容。多位输入的画布使用 SVG foreignObject 中的文本输入框，属性栏也使用二进制文本。仅在 Enter/change 提交，验证长度及字符后以 radix 2 解析并记录一次历史；无效输入恢复原值。渲染时按位宽补足前导 0。鼠标在字段中可选择编辑，右键仍可平移。多位输出以矩形数码屏显示十进制结果，未知显示 ?，单比特输出继续画灯。

## 右键快捷删除（最新规则）

覆盖上述右键从任意位置平移的行为。右键按下时根据命中对象选择手势：空白是 pan，元件（含端口、开关、二进制字段）或导线是 right-delete。后者记录目标 id、初始屏幕点与移动阈值；只在同一目标上释放、累计未超过 6 像素且未取消时，复用统一删除事务。拖动过程中超过阈值后即使移回也不删。删除保存一条历史并立即重算信号；禁止在 contextmenu 中重复删除。保留空格/中键与移动工具作为其他平移方式。

## 删除已保存的逻辑门

语义限定为从“我的逻辑门”元件库移除，不拆除既有电路。被删除但仍在画布或其他门内部使用的定义标记 hidden: true，保留实现以维持信号、端口和存档兼容。未使用的定义真正移除。每次内容事务后，以可见定义和画布上的自定义实例为根，遍历嵌套引用并清理不可达的隐藏定义。版本号仍为 1，hidden 为可选布尔值，旧存档默认可见。

每一行使用两个并列按钮，拖出按钮与删除按钮分离，避免嵌套 button 或误开始拖放。右键条目复用删除事务；拖放过程中不触发库删除。删除/撤销/重做使用已有历史和自动保存。

## 全选与总线线数

选择状态增加 nodes 类型，保存多个节点 id。Ctrl+A 仅作用于画布元件；删除统一将 id 集合用于节点和关联边的过滤，一次提交历史。编辑字段、模态对话框及正在进行的手势不接管全选。选中多个元件时检查器显示数量与删除提示。

总线工具使用专用线数表单。拖放后保留候选节点及世界坐标，打开空白数量字段；通过验证才创建节点。对已有集线器/分线器的门体单击打开同一表单，填入原数量；移动超过点击阈值则只移动，不打开表单。输入数量范围继续为 2–8，与当前信号和存档兼容。工具栏属性和表单复用同一位宽变更函数。

## 二值信号（覆盖三值规则）

信号只保留 0/1，未连接、悬空线或错误驱动使用全零向量。初始求值输出从低电平开始，NAND 按二值规则求值。位宽不符、多输出驱动仍报告连接错误；迭代未收敛时报告反馈错误，并把非输入元件输出清为 0，避免把任意最后一次迭代结果显示成稳定逻辑。界面移除未知图例和 ?，未接线输出显示 0。

## 全部展开/收回

展开以只读视图实现，源模型始终保留，避免引入收回后保存内部修改的新规则。src/expanded.js 递归生成布局与 SVG：自定义门变为带名称的框，所有内部自定义门继续展开，输入输出标记显示为边界接口，最终叶节点为 NAND/总线工具及最外层输入输出。信号取自源模型每层模拟，外部输入通过边界传入，避免为显示重排造成网络误连接。布局按源坐标的列与行排序，自动让开展开后的框。UI 保存原视角和工具，展开中允许平移缩放；保存/导出仍是源模型。收回恢复原视角和编辑状态。
