## 根因与修改

实际副本在旧实现中出现 `RangeError: Invalid string length`。递归展开直接拼接内部 SVG，嵌套的重复结构导致字符串极度膨胀；完整图刷新又与运行和指针操作共用主线程。仅以规则重复门做测试不足以覆盖实际电路。

大型图改为按状态共享图形模板和父子引用，保留全部 35934 个原始叶子的信号与实际实例路径。主页面根据视野绘制可见细节，离开视野的子图不生成 DOM；极小的内部细节在放大后显示。后台 Worker 负责大图生成，合并运行中的待更新请求，不堆积每一步的绘图任务。鼠标按下时不自动步进或应用新图，拖动不会被替换元素打断。步进之间至少让出一帧；用户在首次后台展开期间的相机移动/缩放不被完成后的自动适配覆盖。

图形字符串不再经 JSON 深复制；缓存容量估算先排除过大图形，保留有界缓存。展开中的模拟计算共用一次准备的定义和拓扑上下文。小型图保留原交互方式。

## 滑动视野复用（B42）

2026-10-19。定位到 setCamera 每个移动/滚轮事件调用 viewportSvg，造成可见 SVG 重复生成。现在保存带35%边距的绘制范围，在覆盖范围内且缩放保持原来的80%–125%时直接复用 DOM；连续移动/滚轮仅变换已有画面，补画延后并合并到动作短暂结束后。后台图像结果也不会在连续滚轮中间插入重绘。

同一实际31488门副本通过新增浏览器断言：20次 pointermove 加8次滚轮，原 DOM 保持，viewportSvg 调用0次；跨越缓存边距的大幅平移结束后正确补画，坐标有效。运行中平移、缩放、暂停和收回仍通过（该次暂停129ms，仅为一次测量）。132项核心检查通过；展开缓存、跨模式导线和内部运行浏览器回归均通过，页面错误0。原页与原存档未改，未发布。

## 移动期间像素背景（B43）

2026-10-19。仅减少 SVG 重新生成仍会在变换时重绘大量矢量元素，因此增加当前视野的有限 PNG 像素缓存。实际31488门副本测试生成1955×1686 PNG，像素抽样确认非空（824033个非透明采样），边长限制3072、约600万像素以内。移动时图片层显示、矢量层隐藏；停止后图片层隐藏、矢量层恢复，20次移动和8次滚轮期间无 SVG 再生成。越过边距后补画最终区域，运行平移/缩放/暂停/收回通过，收回后图片元素清除，定义保持、页面错误0。

132项核心检查通过；展开缓存、跨模式临时导线及内部运行浏览器回归通过。异步像素结果匹配视图和区域身份，替换时释放旧对象URL；转换失败保留矢量回退。此优化让大图移动使用已渲染像素，停止后恢复细节，不把完整数百万坐标宽度的电路转换为一张无限占用内存的图片。原用户页面和存档未改，未发布。
