# 全部展开拖动绘制测试报告

日期：2026-10-19。仅本地交付，不推送、不发布。

用户本次反馈针对全部展开后的平移卡顿。原移动缓存图片仍是复杂 SVG 中的 image，每次鼠标移动还会修改 world transform 和网格 patternTransform。本次将缓存图片移到独立 HTML img，使用 translate3d/scale，并通过 requestAnimationFrame 合并移动事件。移动时隐藏 SVG 世界和网格，停止时一次同步原相机、恢复矢量显示；PNG 包含原坐标网格和电路颜色，保持尺寸上限，栅格绘制避开拖动时段。

验证：

- 构建成功，`node --test tests/*.test.cjs`：141 项通过，0 失败。
- `tests/large-live-browser.cjs` 使用本地诊断副本（31488 NAND、2104 延迟线）全部展开验证，页面错误 0。
- 缓存 PNG 为 1955×1686；移动图像为 SVG 世界之外的 HTML IMG，图片实际位移与鼠标位移一致。
- 连续拖动期间 MutationObserver 检测 world transform 更新 0 次、grid patternTransform 更新 0 次；缓存区域内 SVG 生成 0 次。
- 同一帧内注入 200 次移动事件，图片样式变换合并为 1 次；鼠标结束及连续滚轮后，SVG 世界与网格变换和逻辑相机一致。
- 超出缓存边界停止后补绘、运行中平移/缩放、暂停和收回通过；返回后门定义不变，迟到的后台结果不会重新打开视图。
- `expansion-anchor-browser.cjs`、`expansion-layers-browser.cjs`、`wire-force-views-browser.cjs` 回归通过，覆盖定位、切层缓存、1/2/全部、单步/格式及各模式临时导线输入。

测试使用独立浏览器页面，没有刷新或修改用户当前页面。消除了拖动期间复杂 SVG 变换这一开销；测试不保证所有硬件、缩放比例或首次补绘都达到固定帧率。图片尚未准备好时使用按帧合并的矢量回退。
