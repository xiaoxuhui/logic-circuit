# 需求与测试用例

版本：0.1.0；状态：已确认核心规则（2026-10-17）。

产品：逻辑工坊，一个无限画布上的数字电路沙盒。

用户确认：初始唯一逻辑门为与非门 NAND；集线器将多根单比特线打包成总线，分线器按位拆开。

## 规则与验收

- U01：新画布只有一个 NAND；元件库只提供 NAND、输入、输出、集线器、分线器及用户自定义门。
- U02：从元件库按住左键拖出元件，松手放在指定位置；仅点击不自动放置。基础元件和自定义门统一操作。放下后左键拖动门体可再次移动；空白左键拖动绘制折线导线；端口拖动连线；右键按住拖动平移无限地图，兼容空格拖动/中键拖动；滚轮缩放且鼠标位置保持。
- U03：导线吸附端口/线端，输出可连接多个输入；交叉线只有端点落在线上时接通。门移动后端口连线跟随。
- U04：输入可切换 0/1，信号实时传播；NAND 四种真值组合正确。未连接为未知；多驱动冲突、位宽不符反馈可见；不凭空把未知变为 0。
- U05：集线器/分线器支持 2–8 位，标注最低位 b0，往返后每一位保持。总线值可见。
- U06：带输入/输出元件的整个电路可封装，端口从上到下排序，支持继续组合和嵌套；没有有效输入输出时给出提示；限制名称长度。
- U07：选择、删除、撤销、重做、适配视图；自动本地保存与恢复；JSON 导出/导入且校验错误数据。
- U08：桌面和移动尺寸无溢出，触摸拖动和缩放按钮可用；帮助说明控件与快捷键。
- U09：从库拖动时显示随鼠标移动的门预览；松手在画布之外、按 Esc、指针取消或窗口失焦时取消，不留下元件或导线。缩放和平移之后，放置坐标仍对应释放位置。一次放置对应一次撤销，重做不重复创建。
- U10：多位输入使用二进制文本：4 位初值 0000，只允许 0/1，提交不足位数时左侧补零。画布门体和属性栏均可直接输入，按 Enter 或离开字段提交。单比特输入继续使用 0/1 开关。多位输出以数字屏显示对应十进制数值，例如 1010 显示 10，不再画指示灯；单比特输出保留指示灯。

不包含：时钟/触发器/时序设计、在线协作、APK。反馈回路可绘制，但未知反馈不擅自初始化为稳定状态；本版本为组合逻辑实验。
