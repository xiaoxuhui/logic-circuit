# 电线世界模式测试报告

2026-11-02，0.3.26。本地入口位于多米诺骨牌模式下，首次打开转换当前电路。黑空白、橙导线、蓝头、白尾。

9项模型/转换及3项分发检查通过：八邻居1/2头规则、尾部同步更新、与独立全格参考60代逐格比较、直线/分岔/500代闭环、原子导入与编辑、重置基线、NAND4行及全加器8行、嵌套定义、不同总线宽度和汇流、延迟同步4轮，以及无延迟反馈拒绝。转换与演化测试将Core.simulate替换成抛错函数，仍获得正确输出；结果由CA格子产生。

真实浏览器在独立存档中验证当前电路自动转换NAND4行、实际画布RGB四配色、擦除和撤销、连续和单步、右键平移/滚轮缩放、清空前备份恢复、关闭/刷新重开、PNG下载、390像素窄屏、无Worker同核回退。原逻辑电路快照完全不变。截图tests/artifacts/wireworld-mode.png和wireworld.png均为独立示例。

实现边界：逻辑电路按隔离表达式树放置，重复源可能生成多个同步脉冲源，由同一副本输入统一控制；没有宣称已做通用共享总线或跨线复用。20万非空格上限。当前转换需要反馈经过延迟，延迟按下一轮采样；自由画布闭环已验证。输入改变会重置CA副本从第0代传播。转换图案保存源副本用于恢复输入控制，不改变原存档，不上传用户图案。
