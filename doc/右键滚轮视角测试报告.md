# 右键滚轮视角连续性测试报告

2026-10-19：162 项单测通过；right-wheel-browser 和 context-menu-browser 在独立 Chromium 中通过。

修复前，在世界坐标 (20000,15000) 的元件上按右键滚动后，轻移鼠标 2×1 像素，画布偏移从 (-28806.69,-21531.27) 跳到 (-24568,-18361.92)。原因是拖动继续使用缩放前相机基准。

修复后，外部门、空白拖动、内部元件和全部展开四种情况下，缩放保持鼠标世界坐标，后续拖动仅移动 2×1 像素，松开后移动鼠标不再改变视角。滚轮操作不误触发右键点击菜单。原有右键替换、延迟列表和输入隔离交互回归通过。

仅本地修改，未发布，未刷新用户页面。
