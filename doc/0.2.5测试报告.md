# 0.2.5 双键布线平移测试报告

日期：2026-10-18。

## 实现

左键布线期间按住右键按屏幕增量平移相机，草稿保留原起点。松右键继续布线；先松左键立即提交并继续右键平移。支持先右键平移再按左键开始布线；Esc/取消清除草稿和指针捕获。说明及离线dist同步更新。
