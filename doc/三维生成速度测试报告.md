# 三维生成速度优化（2026-10-22）

CPU采样确认寻路重复判障碍、World.at查询和大型方块生成是主要成本。本次保留原A*代价与搜索顺序，先淘汰更差候选，再缓存本次搜索的格子合法性与头顶占用；布线后自然丢弃缓存。绘制复用Simulator已建立的最终粉线邻接表，直接写入可增长Float32Array，返回紧凑缓冲，边界按轴直接更新。

可复现：node tests/minecraft-generation-benchmark.cjs。大电路：node --expose-gc tests/minecraft-generation-benchmark.cjs 623081f4e85e8a221839b271e26416a4ecc8d7e8 --large。固定旧版基线623081f，独立测试存档，用户存档未读取或修改。流式SHA256覆盖全部元数据、GPU批次二进制与每个世界格（含渲染引用和信号），所有模型指纹一致。

小样例先预热，算法顺序每轮交替，以下为五轮中位数：NAND加法器200.0ms→97.0ms（2.06倍）；OR/NOT加法器850.6ms→344.8ms（2.47倍）。30000个可化简门的编译型样例322.6ms→341.4ms，本次未改善展开编译，在该样本约慢6%，不纳入加速结论。

保留30000个物理NAND的大样例含1420309个部件，单轮对比16653.6ms→14870.3ms（1.12倍、耗时减少约10.7%）；完整模型一致。单次大样例不冒充五轮中位数，硬件、电路及运行负载均影响结果，不承诺所有电路同样加速。原始轮次与模型指纹见三维生成性能基准.json。
