# 多米诺骨牌模式测试报告

2026-11-02。新增独立工作线程中的骨牌接触传播模型与Canvas观察界面。输入副本、自动/单步倒牌、重新立牌、速度、平移缩放、延迟跨轮统一采样、全加器示例。原电路不变。

模型验证覆盖与非门4行、全加器8行、嵌套重复实例、总线位序及宽度适配、汇流、延迟反馈的同步采样、临时值、非法反馈拒绝。实际几何测试验证每个预期连接能被前牌碰到；移走桥牌后不能再输出；路径不得交叉；共享的倒牌前沿会实际推动两个分支。没有调用原电路模拟器计算骨牌结果。观察模式采用离散接触与倒牌方向模型，不是连续刚体动力学。

真实浏览器在独立存档验证全加器8行、单步、输入、重立、自动停止、平移缩放、退出/Esc和窄屏；源电路保持不变。早期浏览器回归通过，当前分岔修订后的最终回归及远程CI结果需补记。

边界：为维持平面线路隔离，无法安全复用的分支仍保留独立摆放；大型无交叉展开最多一百万张骨牌。长触发链按保守到达时间表示。几何模型不构成对真实材料摩擦、质量和稳定性的刚体物理证明。
