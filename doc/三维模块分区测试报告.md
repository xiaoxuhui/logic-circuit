# 三维模块分区测试报告

日期：2026-10-20。仅本地构建和提交，不发布。

## 交付行为

NAND 与 OR-NOT 两种模式都显示自定义门模块。各实例有独立颜色和“门名 #编号”，右侧列表保留嵌套缩进。默认显示外层模块；点击任意列表条目，按该门范围定位相机，显示其自身及直接子模块，顶部显示当前模块名称。“全部模块”恢复外层分区及总览。

分区使用彩色底板与轮廓；若同一模块分散在多处，则按行显示同色分段区域，不用一个大框把其他门一起罩住。本次改变归属的显示，不重排物理方块和线路；红石原色、导线强度、门延迟和仿真规则保持不变。分区不参与拾取遮挡，不进入物理方块计数。绘制上限为 128 个可见模块、384 个区域，切换时释放旧的分区实例、轮廓和标签资源。

## 验证

- 48 项相关单元测试通过、0 失败，含 4 项模块测试；三输入加法器两模式八行结果、原有双非门/汇流保护、三万门电路与分发资源检查均通过。
- 模块单测验证三个 XOR 的编号互异、AND 父子关系、两基础模式均有模块信息；分段区域不会跨过其他模块的空隙；嵌套元件只归属于最近的可见模块；相邻区域合并；源数据不变。
- 独立 Chromium：两模式均显示 5 个外层模块；11 个模块的颜色互异；定位 XOR、再定位内部 AND、返回全部模块均成功；信号、运行步数及物理部件数量不变；返回原电路后完整存档与相机相同；430px 窄屏可操作；无页面异常。
- 既有模式切换浏览器测试通过：嵌套标签、八种物理输入组合、暂停状态、窄屏、返回原存档不变。
- 最终构建成功，分发一致性 3 项复查通过，`git diff --check` 通过。
