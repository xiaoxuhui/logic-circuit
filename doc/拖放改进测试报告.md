# 拖放与多位显示改进测试报告

日期：2026-10-17（Asia/Shanghai）；基于 v0.1.0，覆盖用户补充的交互规则。

## 实现

- 右键从空白、门体、端口或开关开始拖动均平移地图，不改变元件或导线。
- 所有基础元件与自定义门从元件库直接拖出，随鼠标显示预览，松手放置；点击不自动放置。放下后可继续左键拖动门体。
- 画布外释放、Esc、指针取消均丢弃预览，不产生元件；坐标依据当前视角计算，不自动寻找其他放置位置。
- 多位输入直接输入二进制，补零显示；例如 4 位从 0000 改为 1010。画布和属性栏可编辑，Enter/失焦提交；非法字符拒绝并恢复原值。
- 多位输出使用矩形数字屏显示十进制结果，1010 对应 10，11111111 对应 255；单比特继续显示灯。
- 存档内部 value 保持数值，旧存档兼容。
