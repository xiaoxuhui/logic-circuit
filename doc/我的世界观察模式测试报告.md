# 我的世界观察模式测试报告

2026-10-20，VERIFIED。本地实现，不推送、不打标签、不发布。

## 交付范围

用户确认使用内置红石方块，只支持观察，不导出，不需要选择 Java/基岩结构格式。左侧新增“我的世界模式”，将当前电路或正在查看的实例转换为独立三维结构，包含自定义门内部。根输入按位显示默认拉杆，根输出按位显示红石灯，NAND 使用火把组件，延迟线使用中继器，集线器/分线器和内部端子保持可辨认。预览显示逻辑引擎计算出的当前信号快照，包括延迟状态及临时导线值；它不是 Minecraft 红石物理模拟，也没有文件导入/导出入口。

WASD 水平移动，空格上升，左右 Shift 均可下降，鼠标锁定或按住拖动观察，Esc 释放鼠标。支持速度、总览、回到入口、重新转换和返回电路。小屏幕提供屏幕方向键。主线程键盘事件隔离，失焦清除移动键，关闭时取消转换、销毁 Worker 和 GPU 资源，原电路、导航层级、视角及存档保持。
