# 替换元件连线保留测试报告

2026-10-19，状态 VERIFIED（本地实现与验证）。

原因：替换元件时，只要新元件没有原方向和序号的端口，原实现就会删除整条导线；内部输入输出元件被替换时，封装接口更新还会删除所有实例中连接该接口的外部线路。

修复：仍存在的同方向、同序号端口保持连接，位宽不同沿用补零/截断；缺失端口只脱离为原坐标自由端，导线 ID、另一端、分支和临时输入仍保留。内部接口改变同步保护根电路及其他定义中的引用实例。普通编辑时主动删除接口的规则保持原样。

实际验证：

- `node --test tests/*.test.cjs`：186 项通过，0 失败。新增 49 种元件类型替换组合，验证全部线路、旋转后的端口坐标、自由端、分支、临时值和原数据不被修改；另外覆盖多个引用实例及嵌套定义的接口减少。
- `node tests/context-menu-browser.cjs`：内外右键替换、全部线路保留、兼容输入和输出端继续连接、缺失输入端留下线头、撤销恢复端点均通过，无页面错误。
- `node scripts/test-browser.cjs`：36 套公开 Chromium 浏览器回归通过；未启用私人存档诊断。
- `node scripts/build.cjs`：本地 dist 已更新；没有刷新用户页面或改写用户存档。
