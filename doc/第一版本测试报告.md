## 核心测试覆盖

1. NAND 四行真值表。
2. 未知信号传播，以及 0 输入决定 NAND 输出 1。
3. 自由导线端点、T 分支、交叉不自动连接。
4. 输出扇出至 NAND 两端。
5. 多输出驱动同一网络的冲突提示。
6. 四位集线器/分线器全部 16 种数据往返。
7. 总线位宽冲突提示。
8. 自定义 NAND 与嵌套自定义门运算。
9. 自定义端口继承位宽及顺序。
10. 无输入/输出边界的封装拒绝。
11. 反馈回路有界求值，保持未知。
12. 有效存档校验与副本隔离。
13. 错误类型、端口、版本、数值、重复 id 等异常存档拒绝。
14. 递归自定义门拒绝。
15. 缺失自定义端口名称拒绝。
16. 按不同定义顺序仍能拒绝超深依赖链。
17. 移动后的锚点更新与投影几何。
