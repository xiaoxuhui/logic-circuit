# 右键删除测试报告

日期：2026-10-17（Asia/Shanghai）。

## 行为

空白处右键拖动平移地图；元件或导线上右键单击，在同一目标上松开时立即删除，不需要先选中或打开确认框。删除元件同时清理它连接的导线，保留其他元件和导线。使用统一历史事务，Ctrl+Z/撤销可完整恢复。

右键从对象上拖动超过 6 屏幕像素后，即使移回也不删除；该手势不平移。Esc、pointercancel 或失焦取消删除。原有移动工具、空格/中键平移和键盘删除保留。

## 实际验证

- 修改前运行 `node tests/browser.cjs`：新用例在 I21 失败，旧实现会从对象上平移，摄像机 X 实际为 140、预期为 45。
- 修改后 `node --test tests/core.test.cjs`：17 passed / 0 failed。
- `node scripts/build.cjs`：成功，生成 dist 四个资源文件。
- 修改后 `node tests/browser.cjs`：41 passed / 0 failed；Chromium 151.0.7922.34，桌面 1440×1000、移动 390×844；pageerror 为 0。
- `node --check src/app.js`、`git diff --check`：通过。
